<a id="-常见注意事项" data-original-heading-id="-常见注意事项" data-translated-heading-id="-common-precautions"></a>
## 📌 Common Precautions

> [!WARNING]
> Do not share your API key or upload it to GitHub, forums, group chats, or public documents.

> [!TIP]
> If a client does not work, check the following first:
>
> * Whether the API endpoint is complete
> * Whether the API key was copied correctly
> * Whether Cockpit Tools is enabled
> * Whether the tool supports a custom API endpoint
> * Whether your local network can reach the API
